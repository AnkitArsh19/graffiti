# Human comparison protocol (not yet run)

These materials define the missing task-completion and usability study. Do not enter values until real participants complete the tasks. Record the exact hosted/local app version or deployment date used in each session.

## Setup

Use the same 1440 x 900 browser window, mouse, browser version, and written instructions for every tool. Give each participant one unscored practice drawing per tool. Assign tool order from cyclic rotations of Graffiti, Excalidraw, draw.io, tldraw, Whitebophir; distribute participants as evenly as possible among orders. Record any account, network, or configuration difference. Avoid coaching during timed tasks.

## T1: Four-node diagram

Create labeled nodes `Problem`, `Evidence`, `Method`, and `Outcome`. Connect `Problem -> Method`, `Evidence -> Method`, and `Method -> Outcome`. Set the `Outcome` node or its label to blue. Move `Evidence` to a new position, then undo that move. Save the final artifact. Score four labels, three directed connections, the style change, and successful undo separately. Count a task as complete only when every required part is present. The final undo must be confirmed from the observation log because it may leave no visible difference in the final file.

## T2: Two-part visual note

Create a first page or region titled `Concept Map` with `Input -> Process -> Output`. Create a second page or region titled `Study Notes` with cue `Input`, note `Gather source data`, and summary `Input is transformed into output`. Use a native page feature where available; otherwise use the closest documented representation and record it. Save, reload, and export the final artifact. Score the three first-part labels, two arrows, second-part cue/note/summary, separation of parts, reload, and export content. Do not treat an app as incapable solely because it uses regions or separate boards instead of pages; record the representation and extra steps.

## Measurements

For each task, record success by rubric item, elapsed seconds, meaningful user actions, undo/error events, and an artifact file or screenshot. Record tool order and prior experience. After both tasks on a tool, collect all ten SUS item responses (1--5) before moving to the next tool. Use anonymous participant IDs. The blank CSV files define the fields and contain no results. Determine the final sample size after a pilot and report it transparently.
